## 实测结论（2026-11-23 完成）

### 覆盖统计
- **CLI 46 命令**：抽查 12 个关键（bookengine/booksource/doctor/quality-loop/restore/backup…）
- **API 128 端点**：GET 50 全扫（25 直接 200 / 21 需参数 / 4 真实无数据）+ POST 关键写面 25 个
- **11 视图**：全部实际遍历，零 console 错误零 JS 异常
- **12 插件**：清单 + manifest 详情渲染
- **安全边界**：路径穿越×4 / confirm 闸门 / 非法 JSON / 超长输入 全拦住

### 发现的缺陷

| # | 严重度 | 现象 | 根因 | 状态 |
|---|---|---|---|---|
| 1 | **中** | 素材库「沉浸」布局不展开行（0/200） | `'<details class="mat-row'+(full?' open':'')+'"'` 把 `open` 写进 class 而非 attribute | ✅ 已修（实测 200/200） |
| 2 | 低 | 发布包 platform=mp 报「不支持」 | mp 不在 pack 平台清单（channels/xhs/zhihu/douyin/juejin/bilibili）；公众号发布走独立 publish 链 | 按设计（记录） |
| 3 | 低 | `/api/action/refine` 动作名 `preview` 非 `improve` | 契约用 preview/adopt/regenerate | 按设计（记录） |
| 4 | 低 | compose 裁决动作 `keep` 非 `adopt` | 契约用 keep/adopt_edited/discard | 按设计（记录） |

### 非缺陷（测试方式问题，已排除）
- CUA 坐标点击卡片空白区不触发（应点内部 `[data-pgopen]`/`[data-mdrow]`）
- 我传 `material_ids` 给 `/api/compose/new`（该端点不接受，须逐个 `/api/compose/add`）
- `/api/article*` 参数是 `path` 而 action 类是 `article`（**两套参数名，属真实不一致但可用**）

### 产品优点（实测确认）
- **AI 诚实拒编**：素材只有标题时明确拒绝生成正文（「本质就是编」），建议补材料——三态裁决哲学的延伸
- **安全边界完整**：路径穿越/confirm 闸门/非法 JSON 全部可读拒绝，零泄露
- **采纳闭环**：6→7 篇真落盘（smoke2-20261123.md）
